# Editor 3D Android

Aplicación móvil de edición 3D con interfaz HTML/CSS/JavaScript y puente nativo en C# (.NET MAUI). Incluye escena 3D local (Three.js), controles táctiles de cámara, cuadrícula, cubos/esferas, selección, lista de objetos, ajuste de color/posición/escala, guardado en datos privados de la app y exportación/importación de escenas JSON.

## APK
El workflow de GitHub Actions compila automáticamente al subir cambios a `main`. Descarga el APK desde el artefacto `Editor3D-Android-APK` de la ejecución. La compilación automática no equivale a probarlo en un teléfono real.

## Estado honesto
Es una primera base funcional, no un editor profesional completo ni un clon terminado. GLB/GLTF, texturas complejas, herramientas de transformación con gizmos, animación, rigging/IK, luces configurables y render offline requieren iteraciones y pruebas adicionales.
